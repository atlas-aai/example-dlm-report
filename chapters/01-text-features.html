1  Text Features

1.1 Conditional text

There are several ways to include text optionally. First, we can use in-line helpers such as dlm_is_pdf() or dlm_is_html(), which can be used to determine the type of output. For example, this is the website version of this report.

We can also include or exclude entire paragraphs using the the .content-visible class with a div.

Read this report chapter by chapter in the browser, or download the complete PDF from the button above.

1.2 Callouts

Callouts can be used to draw attention to some text. Create a callout with:

::: {.callout-note}
## Callout title

Here is the callout text.
:::

1.6 Citations

We can include a normal reference (Thompson, 2026). Or we can include in text, such as with Clark (2016). We can also include an abbreviation, like for the loglinear cognitive diagnostic model (LCDM; Henson et al., 2009).

1.7 Equations

Equations can also be rendered, numbered, and references as shown in Equation 1.1.

\[ P(X_j = x_j) = \sum_{c=1}^C\nu_c \prod_{i=1}^I\pi_{ic}^{x_{ij}}(1-\pi_{ic})^{1 - x_{ij}} \tag{1.1}\]

We can also render math inline. For example, the intercept of Equation 1.2, \(\lambda_{i,0}\), determines the probability of a correct response for a nonmaster, and the main effect \(\lambda_{i,1}\) is the increase in log-odds associated with mastery.

\[ \pi_{ic} = P(X_{ic} = 1|\alpha_c) = \frac{\exp(\lambda_{i,0} + \lambda_{i,1}\alpha_c)}{1 + \exp(\lambda_{i,0} + \lambda_{i,1}\alpha_c)} \tag{1.2}\]

Henson, R. A., Templin, J. L., & Willse, J. T. (2009). Defining a family of cognitive diagnosis models using log-linear models with latent variables. Psychometrika, 74(2), 191–210. https://doi.org/10.1007/s11336-008-9089-5
